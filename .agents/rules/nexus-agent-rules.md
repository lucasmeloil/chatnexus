# Regras do Agente NEXUS Chat

## 🚨 Restrição Estrita de Modificação

1. **Apenas o Solicitado**: Modifique única e exclusivamente os arquivos, trechos de código e requisitos mencionados no prompt atual do usuário.
2. **Sem Iniciativas Não Autorizadas**: Jamais altere outros arquivos ou adicione "melhorias extras" por conta própria sem que o usuário tenha pedido.
3. **Relatório Prévio Obrigatório**: Se encontrar bugs adjacentes, melhorias de desempenho ou ajustes úteis que não foram pedidos, apresente um relatório prévio explicando o motivo da melhoria e pergunte ao usuário se ele autoriza a realização antes de tocar no código.
